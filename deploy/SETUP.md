# 振替・欠席管理システム 公開手順

Claude のアカウントがない保護者・職員も、URL を開くだけで使える状態にするための手順です。

## 仕組み

| 役割 | 置き場所 | 内容 |
|---|---|---|
| 画面 | GitHub Pages（バスアプリと同じ） | 保護者画面・管理画面。データは持たない |
| データとサーバー | Google スプレッドシート + Apps Script | 名簿・欠席・振替を保存。ログイン確認、家庭ごとの絞り込み |

- 保護者は、ログインした家庭の情報しか受け取りません（他の家庭の名前は届きません）。
- 管理画面は管理者パスワードで入ります。パスワードはスプレッドシート側の設定に置き、コードには書きません。
- スプレッドシートの「生徒マスタ」「欠席履歴」「振替予約」シートは、変更のたびに自動で更新されます（見る専用）。
- 名簿をまとめて登録・修正するときは「名簿取込」シートに入力し、管理画面の Sheets ボタン →「名簿を読み込む」を押します。

## 手順 1: スプレッドシートと Apps Script（サーバー）

1. Google ドライブ（soltilogsa.com のアカウント）で、新しいスプレッドシートを作る。名前: `SGAS振替管理データ（テスト）`
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 最初からある `コード.gs` の中身をすべて消し、`deploy/Code.gs` の中身をすべて貼り付けて保存。
4. 左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ: `ADMIN_PASSWORD`
   - 値: 管理画面に入るためのパスワード（職員だけに伝える。8文字以上推奨）
5. エディタに戻り、上の関数の選択で `setupWithSampleData` を選んで「実行」。
   - 初回は権限の確認が出る →「権限を確認」→ 自分のアカウント →「許可」
   - スプレッドシートに「生徒マスタ」「欠席履歴」「振替予約」「名簿取込」シートができれば成功
6. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」→ 表示される「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー

## 手順 2: 画面の公開（GitHub Pages）

1. GitHub で SGIS-ops に新しいリポジトリ `sgas-furikae` を作る（README なし・空のまま）。
2. Claude に「リポジトリを作った」と伝え、手順 1-6 の URL を渡す。
   → Claude がコードを入れ、サーバーの URL を `config.json` に設定して公開用ファイルを用意する。
3. リポジトリの「Settings」→「Pages」→ Source「Deploy from a branch」→ Branch `main` / フォルダ `/docs` →「Save」
4. 数分後に表示される URL（`https://sgis-ops.github.io/sgas-furikae/`）が、保護者・職員に案内する URL。

## 手順 3: テスト

サンプルデータ（架空の生徒）で動作を確認します。

- 保護者: `codmon_sample_ren` / `soltilo123` でログイン → 欠席連絡・振替予約ができるか
- 管理者: 「スクール管理者モード」→ 手順 1-4 のパスワード
- スプレッドシートの「欠席履歴」「振替予約」に反映されているか

## 手順 4: 本番開始

1. Apps Script で `setupEmpty` を実行（サンプルデータが消え、空の名簿になる）。
2. 名簿を登録する（どちらか）
   - 管理画面「コドモン連携」から CSV 取り込み
   - スプレッドシートの「名簿取込」シートに入力 → 管理画面の Sheets ボタン →「名簿を読み込む」
3. 保護者への案内（ログインIDと初期パスワード）は、内容を確認してから送る。

## コードを更新したとき

- 画面だけの変更: Claude が GitHub に反映すれば、数分で URL に反映されます。
- サーバー（Code.gs）の変更: 新しい `deploy/Code.gs` を貼り付けて保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」（URL は変わりません）。

## 注意

- 初期パスワード `soltilo123` は全家庭共通です。本番では、家庭ごとに初期パスワードを変えるか、初回ログイン後の変更を必ずお願いしてください。
- 管理者パスワードを変えるときは、スクリプト プロパティ `ADMIN_PASSWORD` を書き換えるだけです。
- スプレッドシートの共有範囲は、管理する職員だけにしてください（保護者に共有しない）。
